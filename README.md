Netflix Movies & TV Shows Content Analysis

Project Overview
This project analyzes Netflix Movies and TV Shows data using Microsoft Power BI. The objective is to explore content distribution, ratings, genres, countries, and release trends through an interactive dashboard.

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Python (Pandas) for data cleaning

Data Cleaning
- Handled missing values.
- Cleaned unwanted spaces.
- Standardized text values.
- Prepared data for analysis.
- Created a separate genre table for genre analysis.

Dashboard Insights
The interactive dashboard includes:
1. Total Netflix titles, Movies, and TV Shows.
2. Movies vs TV Shows distribution.
3. Top countries by content.
4. Top 10 genres.
5. Content ratings distribution.
6. Titles added by year.
7. Titles by release year.

- Data Visualization
